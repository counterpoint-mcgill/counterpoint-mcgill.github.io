Set up.

One time only. The site needs a GitHub key so it can save the team's edits. The key is locked with the password you choose here; the team only ever types the password.

  1. Create a key on GitHub (sign in as the owner of the site). Check that Resource owner says counterpoint-mcgill.
  2. Under Repository access pick Only select repositories and choose counterpoint-mcgill.github.io.
  3. Under Permissions → Repository, set Contents to Read and write.
  4. Press Generate token, copy it, and paste it below.
